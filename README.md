# Метро Санкт-Петербурга

Интерактивная карта Петербургского метрополитена поверх карты города: клик по двум станциям — и видно маршрут, время в пути и пересадки. Ползунок в разделе «Хронология» показывает историю и перспективы: сеть на конец каждого десятилетия с 1950-х, сегодняшнюю и будущую по схеме развития до 2040 года. Маршрут считается по выбранной сети.

## Откуда данные и насколько им верить

- Станции, координаты и статусы (действует / строится / проектируется) — с перспективной карты [metrostr.ru](https://www.metrostr.ru/map/).
- Годы открытия, ветка красной линии на Пулково, продления до «Коломяжской», «Ручьёв», «Проспекта Маршала Жукова» и северный участок Кольцевой — со схемы развития до 2040 года из отчёта метрополитена за 2025 год ([Фонтанка, 18.08.2026](https://www.fontanka.ru/2026/08/18/76594703/)). Координаты этих станций сняты со схемы привязкой по известным станциям, погрешность — сотни метров.
- Кольцевая линия внесена только северным участком («Большой проспект» — «Полюстровский проспект»): названия остальных её станций схема не даёт.
- «Пулковские высоты» и «КВЦ Экспофорум» есть на схеме без срока — они видны только на шаге «все планы».
- Юго-западный участок 6-й линии (2037) нарисован по схеме, хотя от этой трассировки город, по сообщениям, отказался.
- Время перегонов между действующими станциями — с [spb.metrobook.ru](https://spb.metrobook.ru/), с точностью до минуты.
- Для перегонов без опубликованного времени (вся 6-я линия и все планируемые участки) время оценено по расстоянию между станциями; в файлах линий у них стоит `toNextEstimated`, а в интерфейсе итог помечается знаком «≈».
- Время пересадок — грубая оценка: 3 минуты везде, 1 минута на «Технологическом институте».
- Пересадки на будущие станции 6-й линии («Каретная», «Заставская», «Лиговский проспект-2», «Знаменская») внесены по проекту линии, а не из данных metrostr.ru.
- Линии между станциями — сглаженная кривая через станции, а не реальная трасса тоннелей.
- «Театральная» отмечена как строящаяся: поезда проходят её без остановки. Как год её открытия условно взят 2029-й — срок первого выхода по схеме.
- Железнодорожные станции — те, что нанесены на официальную [схему метрополитена (12.2025)](https://metro.spb.ru/uploads/metromap_12.2025.jpg): пять направлений с тактовым движением (Финляндский вокзал — Сестрорецк и — Мельничный Ручей, Балтийский вокзал — Ораниенбаум-1 и — Красное Село, Витебский вокзал — Павловск), а также Московский и Ладожский вокзалы и платформы у метро (Удельная, Девяткино, Обухово, Рыбацкое). Координаты — из OpenStreetMap; у Московского вокзала, которого в OSM нет точкой, — вручную у головы платформ. Порядок «Пост Ковалёво» → «Ковалёво» взят по координатам OSM. Пересадки на метро — по пунктирам схемы. Время в пути для электричек не считается, в маршрут они не входят.

## Код

- `src/domain` — сеть, история, маршруты; без DOM и карты.
- `src/geo` — сглаживание линий и поправка на широту.
- `src/map` — карта MapLibre: подложка, слои, сборка GeoJSON (`features.ts`), плавные переходы (`fade.ts`), прорисовка маршрута (`trace.ts`), подсказки.
- `src/ui` — панель: поля выбора станций, результат, легенда, сворачиваемые разделы.
- `src/app` — годы ползунка и их подписи, `localStorage` (если он запрещён, настройки просто не сохраняются).
- `src/styles` — CSS по блокам страницы, подключается через `index.css`.
- Тесты лежат в папке `__tests__` рядом с кодом, который проверяют (`src/domain/__tests__/routing.test.ts` и т. п.).
- `src/data/railway.json` — железнодорожные станции (`stations`, id с префиксом `rzd-`, поле `metro` — пешие пересадки) и направления (`routes` — списки id по порядку от вокзала).

## Шрифт

Везде Montserrat. Интерфейс берёт его с Google Fonts. Подписи на карте (и свои, и подложки) MapLibre рисует из SDF-глифов: они собраны из TTF Montserrat (Regular, SemiBold, Italic) и лежат в `public/fonts` вместе с лицензией OFL. Пересобрать: `python scripts/glyphs.py Montserrat-Regular.ttf "Montserrat Regular" public/fonts` (нужны `freetype-py`, `numpy`, `scipy`).
